## 3. 架构合规(v1 核心原则)

- **计算只有一份实现,且在前端**:`BreakevenClient` 直接调用 `lib/calc/calc.ts`(breakevenPrice / netMarginPerAcre / sensitivityGrid / wholeFarm)。6-21 审计中的旧 mock 路径 `lib/breakeven/preview.ts`、`POST /api/breakeven/calculate`、`types/breakeven.ts` 已全部删除。✅
- **禁用期货价**:盈亏一律用手填现金价;`futuresSymbol` 仅为带 v1-OUT 注释的占位字段。✅
- **数据驱动**:`config/crops.ts` / `costModel.ts` / `states.ts`,无州/作物硬编码分支。✅
- **状态管理**:新增 Zustand `farmStore`,/farm 与 /breakeven 共享状态(解决 6-21 R2/步骤5)。✅
- **无 scope creep**:未发现行情/预警/保险/PDF/深度子计算器代码。✅
- familyLiving:引擎以可选参数支持(默认 0),UI 未露出 —— 契约允许(optional in v1)。

## 5. 部署注记(VM 演示相关)

- `.env.local` 设了 `NEXT_PUBLIC_API_BASE=http://localhost:8080`:登录状态下 farm/scenario 请求会打真实 Dart 后端。VM 上若未部署后端,已登录用户的保存/读取会失败(未登录/无 token 时走本地 fallback)。演示要完整持久化需在 VM 同机跑 Dart 后端,或清空该变量走 mock。
- `NEXT_PUBLIC_*` 构建期固化,改 env 后需重新 `npm run build`。
